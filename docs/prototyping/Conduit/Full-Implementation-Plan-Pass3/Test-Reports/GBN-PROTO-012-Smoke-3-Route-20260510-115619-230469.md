## Scope

This run executed Smoke 3 with observability backend enforcement disabled. Functional route validation was still gated by three evidence classes:

1. API completion gates for NewCreator local-DHT readiness, `SendDummy`, receiver persistence, and Publisher decrypt/hash validation.
2. Real DHT state dumps from the Publisher, HostCreator, NewCreator, ExitBridge metadata endpoints, and role-specific local-DHT surfaces.
3. ChainID-bearing pod logs from the NewCreator, selected ExitBridge, Publisher receiver, and Publisher authority for both the normal and forced-failover route.

The initial Smoke 3 preflight found the NewCreator not onboarded and intentionally ran the Smoke 2 bootstrap fallback before packet transfer. The fallback completed bootstrap and produced the local DHT state used by this run.
